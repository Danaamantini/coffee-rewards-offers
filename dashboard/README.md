# Power BI report

This directory contains the visual specification and portfolio assets for the
Coffee Rewards report.

## Report pages

1. **Dashboard** - executive KPIs, conversion funnel, offer-type performance,
   channel performance, and income-level completion.
2. **Funnel Analysis** - received, viewed, and completed volume by offer type,
   with view and completion rates by channel and offer type.
3. **Effectiveness Analysis** - completion by age, income, and gender, plus a
   comparison of customers with and without demographic data.
4. **Data Exploration** - dataset and metric selectors with a category chart
   and exact-value table.

## Files

- `charts.md` documents the Power BI field mapping and the analytical purpose
  of each visual.
- `assets/coffee-rewards-dashboard.png` is the static portfolio cover image.
- `assets/coffee-rewards-dashboard-demo.gif` cycles through all report pages.
- The remaining PNG files provide full-resolution views of the detail pages.
