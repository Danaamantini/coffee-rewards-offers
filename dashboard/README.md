# Power BI report

This directory contains the visual specification and portfolio assets for the
final Coffee Rewards report. The report is organized around decisions rather
than exploratory worksheets.

## Report pages

1. **Executive Summary** - completion, response-time, and reward-cost KPIs;
   overall funnel; reward-cost efficiency; and the recommended budget action.
2. **Funnel & Response** - volume by funnel stage, view and completion rates by
   channel and offer type, and median response time by offer type.
3. **Customer Segments** - completion by age, income, and gender, plus the
   behavioral gap for customers without demographic data.
4. **Offer Economics** - reward cost per received offer, break-even margin,
   modeled sales per reward dollar, and gross-margin sensitivity.

## Portfolio assets

- `assets/coffee-rewards-dashboard.png` - stable cover image used by the root

- `assets/customer-segments.png` - full-resolution Customer Segments page.
- `assets/offer-economics.png` - full-resolution Offer Economics page.
- `assets/coffee-rewards-dashboard-demo.gif` - animated walkthrough of the four
